# Electronics Quiz Competition — v3

This version fixes the JavaScript error that prevented the Start Quiz button from working on GitHub Pages.

## Correct GitHub repository structure

The files inside this folder must be placed directly in the repository root:

ECE-QUIZ-COMPETITION/
- index.html
- admin.html
- README.md
- css/style.css
- js/quiz.js
- js/admin.js
- data/questions.json

Do NOT create:
ECE-QUIZ-COMPETITION/electronics_quiz_website/index.html

## GitHub Pages

Settings -> Pages -> Deploy from branch -> main -> /(root).

Then open:
https://pammohit.github.io/ECE-QUIZ-COMPETITION/

If the old version still appears, press Ctrl+F5 or use a private/incognito window.

## Demo limitation

Results are stored in browser localStorage only. This is for testing. A real competition requires a shared database, organizer authentication, and server-side validation.
